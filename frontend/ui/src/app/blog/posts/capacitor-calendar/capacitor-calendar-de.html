Viele Apps arbeiten mit Terminen: Buchungen, Verabredungen, Events, Fristen. Früher oder später wünschen sich die Nutzer einen Button, der den Termin in ihren eigenen Kalender einträgt. In einer Capacitor-App kommt die Web-Schicht allein nicht an den Kalender des Geräts heran. Dafür brauchst du ein natives Plugin.

Genau dafür habe ich Capacitor Calendar geschrieben, und ich pflege es bis heute. Dieser Artikel stellt das Plugin vor und bringt dich in wenigen Minuten von der Installation zu deinem ersten Kalendereintrag.

Was das Plugin kann

@ebarooni/capacitor-calendar verbindet deine Capacitor-App mit dem nativen Kalender. Auf iOS und Android kannst du Termine anlegen, bearbeiten und auflisten, Kalender verwalten und nach Kalenderberechtigungen fragen. Auf iOS unterstützt es auch Erinnerungen. Im Web erstellt es stattdessen eine .ics-Datei zum Herunterladen, weil ein Browser nicht in einen Gerätekalender schreiben kann.

Es ist ein normales Capacitor-Plugin. Es funktioniert also mit Ionic, Angular, React, Vue oder jedem anderen Framework, das deine Oberfläche rendert. Die aktuelle Tabelle der Funktionen pro Plattform steht in der README.

Plugin installieren

Füge das Paket hinzu und synchronisiere die nativen Projekte:

npm install @ebarooni/capacitor-calendar
npx cap sync

So installierst du die Version für die aktuelle Capacitor-Version. Nutzt deine App eine ältere Capacitor-Hauptversion, zeigt dir die Kompatibilitätstabelle, welches npm-Tag du installieren musst.

Berechtigungen deklarieren

Der Kalender enthält persönliche Daten. Deshalb fragen beide Plattformen den Nutzer, bevor eine App ihn verwenden darf. Deklariere zuerst, was deine App braucht. Trage nur die Einträge ein, die deine App wirklich nutzt.

Android

Füge die Kalenderberechtigungen in android/app/src/main/AndroidManifest.xml ein: 

<uses-permission android:name="android.permission.READ_CALENDAR" />
<uses-permission android:name="android.permission.WRITE_CALENDAR" />

iOS

Füge Nutzungsbeschreibungen in ios/App/App/Info.plist ein. iOS zeigt diesen Text im Berechtigungsdialog. Erkläre also, warum deine App den Zugriff braucht: 

<key>NSCalendarsFullAccessUsageDescription</key>
<string>Diese App braucht Zugriff, um deine Termine zu lesen und zu verwalten.</string>

iOS hat eigene Schlüssel für reinen Schreibzugriff und für Erinnerungen. Der Setup-Abschnitt der README listet sie alle auf.

Zugriff anfragen und Termin anlegen

Jetzt der Code. Frage zuerst nach dem Zugriff und lege dann den Termin an. Zeitangaben sind Unix-Zeitstempel in Millisekunden. 

import { CapacitorCalendar } from '@ebarooni/capacitor-calendar';

const { result } = await CapacitorCalendar.requestFullCalendarAccess();

if (result !== 'granted') {
  throw new Error('Calendar permission denied');
}

// Ein Termin, der in einer Stunde beginnt und eine Stunde dauert
const startDate = Date.now() + 60 * 60 * 1000;
const endDate = startDate + 60 * 60 * 1000;

const { id } = await CapacitorCalendar.createEvent({
  title: 'Produkt-Review',
  location: 'Büro',
  startDate,
  endDate,
});

Speichere die zurückgegebene id, wenn du den Termin später ändern oder löschen willst.

Im nativen Editor bestätigen lassen

Manchmal willst du nicht direkt in den Kalender schreiben. Vielleicht möchte der Nutzer erst einen Kalender wählen, eine Erinnerung hinzufügen oder die Uhrzeit ändern. Öffne dafür den nativen Termin-Editor mit bereits ausgefüllten Feldern: 

await CapacitorCalendar.createEventWithPrompt({
  title: 'Planungsrunde',
  location: 'Büro',
  startDate: Date.now() + 24 * 60 * 60 * 1000,
  endDate: Date.now() + 25 * 60 * 60 * 1000,
});

Der Nutzer sieht den vertrauten Systemdialog und speichert den Termin mit einem Tipp. Im Web fragt derselbe Aufruf nach einer Bestätigung und bietet eine .ics-Datei zum Herunterladen an.
