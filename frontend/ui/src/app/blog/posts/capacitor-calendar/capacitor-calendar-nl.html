Veel apps werken met datums: boekingen, afspraken, evenementen, deadlines. Vroeg of laat vragen gebruikers om een knop die die datum in hun eigen agenda zet. In een Capacitor-app kan de weblaag niet zelf bij de agenda van het apparaat. Daarvoor heb je een native plug-in nodig.

Precies daarvoor heb ik Capacitor Calendar geschreven, en ik onderhoud het nog steeds. Dit artikel stelt de plug-in voor en brengt je in een paar minuten van de installatie naar je eerste agenda-afspraak.

Wat de plug-in doet

@ebarooni/capacitor-calendar verbindt je Capacitor-app met de native agenda. Op iOS en Android kun je afspraken maken, bewerken en opvragen, agenda's beheren en om agendatoestemming vragen. Op iOS ondersteunt het ook herinneringen. Op het web maakt het in plaats daarvan een .ics-bestand om te downloaden, omdat een browser niet in de agenda van een apparaat kan schrijven.

Het is een gewone Capacitor-plug-in. Hij werkt dus met Ionic, Angular, React, Vue of elk ander framework dat je interface rendert. De actuele tabel met functies per platform staat in de README.

De plug-in installeren

Voeg het pakket toe en synchroniseer de native projecten:

npm install @ebarooni/capacitor-calendar
npx cap sync

Zo installeer je de release voor de huidige Capacitor-versie. Gebruikt je app een oudere hoofdversie van Capacitor, dan vertelt de compatibiliteitstabel welke npm-tag je moet installeren.

De toestemmingen declareren

De agenda bevat persoonlijke gegevens. Daarom vragen beide platforms het de gebruiker voordat een app hem mag gebruiken. Declareer eerst wat je app nodig heeft. Voeg alleen de regels toe die je app echt gebruikt.

Android

Voeg de agendatoestemmingen toe aan android/app/src/main/AndroidManifest.xml: 

<uses-permission android:name="android.permission.READ_CALENDAR" />
<uses-permission android:name="android.permission.WRITE_CALENDAR" />

iOS

Voeg gebruiksbeschrijvingen toe aan ios/App/App/Info.plist. iOS toont deze tekst in de toestemmingsdialoog, dus leg uit waarom je app toegang nodig heeft: 

<key>NSCalendarsFullAccessUsageDescription</key>
<string>Deze app heeft toegang nodig om je afspraken te lezen en te beheren.</string>

iOS heeft aparte sleutels voor alleen-schrijven-toegang en voor herinneringen. De setup-sectie van de README noemt ze allemaal.

Toegang vragen en een afspraak maken

Nu de code. Vraag eerst om toegang en maak dan de afspraak. Tijden zijn Unix-tijdstempels in milliseconden. 

import { CapacitorCalendar } from '@ebarooni/capacitor-calendar';

const { result } = await CapacitorCalendar.requestFullCalendarAccess();

if (result !== 'granted') {
  throw new Error('Calendar permission denied');
}

// Een afspraak die over een uur begint en een uur duurt
const startDate = Date.now() + 60 * 60 * 1000;
const endDate = startDate + 60 * 60 * 1000;

const { id } = await CapacitorCalendar.createEvent({
  title: 'Productreview',
  location: 'Kantoor',
  startDate,
  endDate,
});

Bewaar de teruggegeven id als je de afspraak later wilt wijzigen of verwijderen.

Laat de gebruiker bevestigen in de native editor

Soms wil je niet direct in de agenda schrijven. Misschien wil de gebruiker eerst een agenda kiezen, een melding toevoegen of de tijd aanpassen. Open daarvoor de native afsprakeneditor met de velden al ingevuld: 

await CapacitorCalendar.createEventWithPrompt({
  title: 'Planningsoverleg',
  location: 'Kantoor',
  startDate: Date.now() + 24 * 60 * 60 * 1000,
  endDate: Date.now() + 25 * 60 * 60 * 1000,
});

De gebruiker ziet het vertrouwde systeemscherm en bewaart de afspraak met één tik. Op het web vraagt dezelfde aanroep om bevestiging en biedt hij een .ics-bestand aan om te downloaden.
