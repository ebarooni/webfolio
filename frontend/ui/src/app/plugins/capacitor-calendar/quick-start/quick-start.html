1. 1

    Install the plugin

    Add the package and sync the native projects. On {{ olderCapacitor.capacitor }}, install the {{ olderCapacitor.tag }} tag instead.

  2. 2

    Declare the permissions

    The plugin uses the native calendar APIs. Add the usage descriptions on iOS and the calendar permissions on Android. If you only create events on iOS, the write-only key is enough.

  3. 3

    Call the API

    Request access, then create, list or edit events. Dates are Unix timestamps in milliseconds.
